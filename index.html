EquipMaster Backup

EquipMaster Backup is an internal tool used by the owner of this Google account to store backup archives of the EquipMaster equipment-management system in the owner's own Google Drive.

The tool runs on a private server and uses rclone with the Google Drive scope drive.file, so it can only see and manage the files it creates itself. It does not read any other files in Google Drive and is not offered to the public.

Công cụ nội bộ: lưu bản sao lưu của hệ thống EquipMaster vào Google Drive của chính chủ tài khoản.
